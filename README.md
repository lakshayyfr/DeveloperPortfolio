
# DeveloperPortfolio

A Beginner Developer Ecosystem Portfolio demonstrating
practical skills in Linux, Bash scripting, Git, REST APIs,
Python and professional development.

## Project Sections

### 1. Linux Commands and System Documentation

- Hardware and operating system information
- Linux command outputs
- Binary number conversions

[Linux Documentation](Linux/)

### 2. Shell Scripting and Automation

- Automated system information report
- Compressed folder backup script
- Backup logging and process monitoring

[Shell Scripts](ShellScripts/)

### 3. GitHub and API Interaction

- GitHub REST API
- JSONPlaceholder API
- JSON data filtering using jq
- Python data demonstration

[API Documentation](API/)

### 4. Developer Portfolio and Career Roadmap

- Technical resume
- Semester-wise learning roadmap
- Professional profiles
- Portfolio website
