# My AI/ML Learning Roadmap

## Semester 1 (2026)
- Practised Python basics, Linux, Bash, Git, HTML, CSS and REST APIs.
- Milestone: DeveloperPortfolio capstone.

## Semester 2
- Learn data structures, algorithms, SQL, databases and web basics.
- Study linear algebra, probability and statistics.
- Certification goal: Microsoft Azure AI Fundamentals or its current equivalent before the end of Semester 2.

## Semesters 3–4: AI/ML specialization
- Learn NumPy, pandas, data preparation and visualization.
- Study regression, classification, clustering and model evaluation.
- Plan small, documented machine learning projects.

## Semesters 5–6
- Study neural networks, deep learning and responsible AI.
- Learn model deployment basics and prepare for internships.

## Semesters 7–8
- Develop and evaluate an AI/ML final-year project.
- Revise DSA, SQL and ML fundamentals for placements.
